# concepts/

Hard-won domain knowledge, one lesson per file, added as the project teaches us.

A concepts page earns its place by being learned the hard way — a debugging session, a wrong assumption the field corrected, a subtlety of double-entry accounting or bank-statement formats that cost real time. Name files after the lesson (e.g. `csv-date-formats-lie.md`). Link every new page from [../INDEX.md](../INDEX.md) or it will never be read.
