# raw/

Append-only ground truth: logs, evidence, pastes.

Agents may **add** files here (dated filenames: `YYYY-MM-DD-what-it-is.ext`). Agents **never edit or delete** anything here — not even their own earlier additions. If something in raw/ turns out to be misleading, write a correction as a new file or a concepts/ page that points at it; the original stays.
